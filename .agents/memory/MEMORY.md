- [Date serialization for Drizzle → Zod](drizzle-date-serialization.md) — Drizzle returns Date objects but Zod schemas expect strings; always serialize via JSON.parse(JSON.stringify(data)) before .parse().
- [Orval Zod integer bug](orval-zod-integer.md) — Orval 8.23 + Zod v3: use `type: number` not `type: integer` in OpenAPI specs to avoid zod.int() codegen errors.
